# Shambhu Sharan Kumar: Portfolio

Next.js 14 · React · TypeScript · Tailwind CSS · Lucide icons

## Run locally
```
npm install
npm run dev
```

## Edit your content
All content lives in `lib/data.ts`. Replace every `[PLACEHOLDER]` (email, phone, LinkedIn, GitHub, employment dates).
Items still in square brackets are treated as "not set" and the social icons link to the contact section.

## Deploy to Vercel
1. Push this folder to GitHub.
2. Import the repo at vercel.com/new (framework is auto-detected as Next.js).
3. Optional: set `NEXT_PUBLIC_SITE_URL` (e.g. https://yourname.vercel.app) for correct Open Graph URLs.

The contact form opens the visitor's email app (mailto) once your email is set. For a server-side form, add a service such as Formspree.
